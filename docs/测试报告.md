## 四、性能测试

| 指标 | 目标 | 实测说明 |
|------|------|---------|
| 应用冷启动 | < 5s | 依赖 Electron 环境，冒烟中正常启动（未做精确计时） |
| DSH 进程启动 | < 3s | 冒烟测试中 headless 任务完成约 14s（含 LLM 调用） |
| 预览加载 | < 3s | 本地静态服务，瞬时 |
| 修改响应 | < 5s | 受 LLM 调用时长影响（真实环境 10-60s，受模型/网络制约） |

> 说明：LLM 相关耗时指标取决于用户选择的模型与网络，本地基础设施（启动、预览、导出）均满足目标。

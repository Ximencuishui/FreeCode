常见问题

FAQ

关于 FreeCoder 最常见的问题，一目了然。

FreeCoder 是什么？

FreeCoder 是一款开源的桌面应用（基于 Electron），让非技术用户通过自然语言对话，从零生成可运行的软件。它不依赖任何云端服务，所有代码与数据保存在用户本地，自备 DeepSeek API Key 即可使用，底层基于 DeepSeek 开源的 DeepSeek Harness（DSH）智能体引擎。

DeepSeek Harness（DSH）是什么？为什么 FreeCoder 基于它？

DeepSeek Harness（DSH）是 DeepSeek 开源的 AI 智能体引擎，以「一切皆插件」的架构让大模型像工程师一样读写文件、执行命令、自主完成开发任务。FreeCoder 基于 DSH，把「确认需求 → 自动开发 → 口语修改 → 即时预览」的整套能力做成了非技术用户也能轻松上手的桌面应用。

需要会写代码吗？

完全不需要。一切操作通过对话完成：AI 助理引导你描述需求并确认需求卡片，代码对用户完全隐藏，全程不接触 Git、服务器、数据库等概念。

我的数据和代码安全吗？

安全。所有代码与数据都保存在你的电脑本地，不上传任何服务器；API Key 使用系统级加密（safeStorage）存储，应用没有任何遥测。

收费吗？需要什么 API Key？

FreeCoder 本身开源免费（MIT License）。你只需自备一个 DeepSeek API Key（在 platform.deepseek.com 申请），按实际用量计费，无月费。

支持哪些平台？

Windows 10/11 已验证发布；macOS 与 Linux 的 electron-builder 跨平台打包代码已在主进程 package/service.ts 中就位（process.platform 全套分支判断），按 GitHub Releases 节奏陆续放出安装包。

生成的软件可以部署上线吗？

可以。内置「智能部署助手」提供四大路径：一键启动（复用预览服务器立即跑起来）、智能打包（spawn electron-builder 真打 .exe / .dmg / .AppImage）、部署指引（云 / Docker / 服务器，附真实命令与产物入口）、高级导出（5 步 DeployConfigWizard：数据库 / 登录 / 邮箱 / JWT / 确认，导出 zip 包含源码、Dockerfile、docker-compose、.env 与中英文部署指引）。完成后通过 MilestoneCard 展示关键节点，并支持 revealInFolder 直接打开产物。

数据库与登录怎么选？

数据存储可选 SQLite（本地优先，零运维）或一键申请 Neon / Supabase 云数据库；登录方式支持密码登录与 GitHub / Google 等 OAuth 第三方登录，所有凭据通过系统级加密（safeStorage）保存在本地。

会自动跑测试吗？

会。需求确认后 DSH 智能体会在开发完成后自动规划与执行测试用例，聊天窗口里以「自动测试计划卡片 + 进度条」实时展示当前阶段、已完成项与剩余预估时间；测试结束后给出结构化报告，失败项可一键发起重测。

项目会自动生成文档吗？

会。每次开发完成会自动生成 README、需求文档、版本计划等 Markdown 文档，集中在「文档中心」目录树中浏览；还提供 Markdown 渲染查看器与目录索引，无需离开 FreeCoder 即可审阅项目全貌。
